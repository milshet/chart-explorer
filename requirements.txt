# chart-sherpa -- Python dependencies

# ---------------------------------------------------------------------------
# INSTALL TORCH FIRST, SEPARATELY. It is deliberately NOT listed below.
# ---------------------------------------------------------------------------
# The correct torch wheel depends on your GPU and CUDA version, and a plain
# `pip install torch` pulls a default wheel that may not support your card --
# silently replacing a working install with one that cannot see the GPU.
#
#   CUDA 12.8 (Blackwell: RTX 50-series, sm_120):
#     pip install --index-url https://download.pytorch.org/whl/cu128 torch torchvision
#
#   CUDA 12.1 / 12.4 (Ada, Ampere):
#     pip install --index-url https://download.pytorch.org/whl/cu124 torch torchvision
#
#   CPU only (evaluation of saved predictions; no training or inference):
#     pip install torch torchvision
#
# Reference environment for the published results:
#   Python 3.10, torch 2.12.0.dev20260408+cu128, RTX 5070 Ti Laptop (12.8 GB, sm_120)
#
# Blackwell note: sm_120 requires CUDA 12.8 and, at time of writing, a nightly
# torch build. Stable releases on the default PyPI index will install but fail
# at the first kernel launch. The notebook preflight cell checks for this.
#
# Then:  pip install -r requirements.txt
# ---------------------------------------------------------------------------
